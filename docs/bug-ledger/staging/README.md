# File staging and transfer

This file contains the complete ledger entries assigned to this component. See the [split index](../index.md) or the [flat compatibility ledger](../../bug-ledger.md).

| --- | --- | --- | --- | --- | --- |
| BUG-007 | Stage-out/content versioning | A source file changed during asynchronous transfer can publish bytes from an obsolete version. | `ParslFileTransferRetry.tla`; staging runtime probes | Publish only a checksum/version-matched transfer, otherwise retry or mark stale. | Reproduced; candidate fixed model passes |
| BUG-025 | File transfer versioning | A source file can change after asynchronous stage-out begins; the current rsync wrapper can report success for the old bytes and release a consumer with obsolete content. | `ParslFileTransferRetryCurrent.cfg` (133 generated/47 distinct, `PublicationSafety`); fixed 184 generated/54 distinct; `tests/test_rsync_stageout_version_runtime.py` | Publish only a version/checksum-matched transfer; otherwise mark stale and retry before DataFuture readiness. | Reproduced in model and rsync wrapper probe; source fix pending |
| BUG-037 | Input staging list aliasing | `DataFlowKernel._add_input_deps` rewrites elements of the caller-owned `kwargs['inputs']` list while replacing files with staged values. Reusing that list after submission observes staged/local objects instead of the original input descriptors. | `ParslInputListMutationCurrent.cfg` (2-state `CallerListPreserved` counterexample); fixed 4 generated/2 distinct; `tests/test_input_list_mutation_runtime.py` | Copy input collections before staging rewrites, preserving caller-owned lists and file descriptors. | Reproduced in model and runtime probe; candidate fixed model passes |
| BUG-038 | Output staging list aliasing | `DataFlowKernel._add_output_deps` rewrites elements of the caller-owned `kwargs['outputs']` list while replacing files with clean copies. | BUG-066 | File clean-copy local-path aliasing | `File.cleancopy()` must preserve the URL while clearing mutable site-local `local_path`. The unsafe branch aliases the old worker-local path into the copy, so a staged copy can point at a path belonging to another site. | `ParslFileCleanCopyCurrent.cfg` (2-state `LocalPathIsClean` counterexample); fixed 4 generated/2 distinct; `tests/test_file_clean_copy_runtime.py::test_clean_copy_preserves_url_and_clears_local_path` | Clear site-local staging metadata when copying while retaining immutable URL metadata. | Reproduced in model and runtime probe; candidate fixed model passes |
| BUG-067 | Stage-in wrapper failure orphan | `DataManager.optionally_stage_in` starts the provider transfer before `replace_task`. If wrapper construction raises, the stage-in Future remains pending and the caller receives an exception with an active transfer that has no task owner. | `ParslDataManagerStageInOrderingCurrent.cfg` (3-state `NoOrphanTransfer` counterexample); fixed 4 generated/2 distinct; `tests/test_data_manager_stage_in_ordering_runtime.py::test_wrapper_failure_leaves_started_stage_in_future_currently` | Prepare/validate the wrapper before starting transfer, or cancel and clean up the transfer when wrapper construction fails. | Reproduced in model and runtime probe; candidate fixed model passes |
| BUG-068 | Stage-out wrapper failure orphan | `DataManager.stage_out` starts the provider transfer before `replace_task_stage_out`. If output wrapper construction raises, the stage-out Future remains pending and task setup has failed. | `ParslDataManagerStageOutOrderingCurrent.cfg` (3-state `NoOrphanTransfer` counterexample); fixed 4 generated/2 distinct; `tests/test_data_manager_stage_out_ordering_runtime.py::test_wrapper_failure_leaves_started_stage_out_future_currently` | Prepare/validate the output wrapper before starting transfer, or cancel and clean up the transfer on wrapper failure. | Reproduced in model and runtime probe; candidate fixed model passes |
| BUG-076 | FTP transfer connection leak | FTP stage-in opens a connection and calls `quit()` only on the normal transfer path. If `retrbinary` raises, the current wrapper leaves the socket open after the transfer has failed. | `ParslFTPConnectionCleanupCurrent.cfg` (2-state `FailureCleanupSafety` counterexample); fixed/success configurations 4 generated/2 distinct; `tests/test_ftp_connection_cleanup_runtime.py::test_transfer_failure_leaves_ftp_connection_open_currently` | Close the FTP connection in a finally-equivalent cleanup path on both success and transfer failure. | Reproduced in model and runtime probe; candidate fixed model passes |
| BUG-077 | HTTP partial destination publication | HTTP stage-in writes response chunks directly to the final destination. | BUG-078 | Zip stage-in partial destination | Zip stage-in writes an archive member directly to the final output. | BUG-079 | Zip stage-out duplicate archive entry | If source cleanup fails after archive publication, retry appends another member with the same name. | BUG-085 | HTTP stream failure leaks response | HTTP stage-in iterates a streaming `requests.Response` without a `finally`/`close` path. | BUG-105 | FTP stage-in publishes partial destination on failure | `_ftp_stage_in` writes incoming `retrbinary` chunks directly to the requested destination. | BUG-121 | LocalProvider failed launch leaves submit script | `LocalProvider.submit` writes the worker script before invoking the launcher.
