# Monitoring and database

| BUG-199 | Monitoring UDP malformed pickle kills router | `MonitoringRouter.process_message` verifies the HMAC and then calls `pickle.loads` without a decode-error boundary. An authenticated but malformed UDP payload therefore escapes the listener, preventing later valid monitoring datagrams from reaching the database queue. | `ParslMonitoringUDPPickleIsolationCurrent.cfg` (counterexample to `RouterSurvivalSafety`); fixed configuration passes; `tests/test_monitoring_udp_pickle_runtime.py` | Catch malformed pickle payloads, log/discard them, and keep the UDP router alive for subsequent valid messages. | Reproduced against the installed UDP monitoring router; candidate fixed model passes |
| BUG-210 | SQLite monitoring foreign key not enforced | `Database.Status.run_id` declares a foreign key to `WORKFLOW`, but `Database` creates a default SQLite engine without enabling SQLite foreign-key enforcement. A STATUS row referencing a missing workflow is therefore committed as an orphan. | `ParslMonitoringForeignKeyCurrent.cfg` (counterexample to `ForeignKeySafety`); fixed and normal configurations pass; `tests/test_monitoring_foreign_key_runtime.py::MonitoringForeignKeyRuntimeTest::test_orphan_status_row_is_accepted_by_current_sqlite_engine` | Enable SQLite foreign-key enforcement on every connection or validate/defer parent existence before committing STATUS rows. | Reproduced against the installed SQLAlchemy monitoring Database; candidate fixed model passes |
| BUG-216 | Monitoring workflow duration silently dropped | `DatabaseManager.close()` passes `workflow_duration` to `Database.update`, but the `WORKFLOW` schema has no such column. SQLAlchemy bulk update mappings silently ignore the unknown field, so abnormal-close duration is never persisted. | `ParslMonitoringWorkflowDurationCurrent.cfg` (counterexample to `DurationPersistenceSafety`); fixed and normal configurations pass; `tests/test_monitoring_workflow_duration_runtime.py` | Persist the duration in the schema and validate update fields instead of silently dropping unknown columns. | Reproduced against the installed SQLAlchemy monitoring Database; candidate fixed model passes |
