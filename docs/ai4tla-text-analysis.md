# Session Text Visualization

This analysis applies classic technical-text statistics to exposed session
`output_text` fields. It does not export or archive the transcript. Common
English, tool, and programming boilerplate terms are filtered; the remaining
terms are counted globally, by activity phase, and by day.

The most frequent retained terms include:

```text
tlc, runtime, fixed, provider, current, future, probe, monitoring,
executor, parsl, push, github, smoke, states, retry, join, htex,
task, model, worker
```

The SVG visualization is
`site/dist/text-term-analysis.svg`:

- left panel: global technical-term frequency;
- right panel: phase-normalized term heatmap;
- hover text: the normalized count for a term and phase.

The normalized heatmap helps distinguish generic high-volume vocabulary from
terms that are unusually characteristic of a phase. For example, `tlc`,
`probe`, and `runtime` are verification-oriented, while `provider`,
`executor`, and `htex` identify infrastructure and communication work.

The machine-readable result is `docs/ai4tla-text-analysis.json`, generated by
`scripts/analyze_session_text.py`. This is descriptive corpus analysis, not a
quality or reasoning score. Technical token frequency is affected by prompts,
tool output, repeated test logs, and the classifier's vocabulary choices.
